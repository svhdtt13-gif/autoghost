# AutoGhost V1 — P2.1 Input-Origin Diagnostic

Status: **IMPLEMENTED — DIAGNOSTIC ONLY; P2 REMAINS BLOCKED_BY_INJECTED_INPUT**

## Scope

`tests/AutoGhost.P2InputOriginDiagnostic` is a read-only probe. It does not use `WindowsInputRecorder`, does not create an `ActionDefinition`, does not dispatch input, and does not alter the injected-input filter.

It registers mouse and keyboard Raw Input with `RIDEV_INPUTSINK`, reads `WM_INPUT` device handles/names, and independently observes low-level keyboard/mouse hook flags. Each observation includes timestamp, stage, device/low-level kind, foreground HWND/PID/process/title, and exact qnyh Role ID match when applicable.

## Matrix

The executable runs two timed stages:

1. `NOTEPAD`: focus Notepad and perform one mouse and one keyboard action.
2. `QNYH`: focus the exact bound qnyh HWND and perform one mouse and one keyboard action.

The result distinguishes:

- Raw device input observed + low-level non-injected event;
- Raw device input observed + low-level injected-only event;
- no Raw Input device event observed.

Raw Input is evidence about the device/source path only. It never authorizes recording or replay. The existing `LLKHF_INJECTED`/`LLMHF_INJECTED` gate remains authoritative.

Follow the two console prompts and provide one harmless physical mouse action and one keyboard action in each stage. Review the generated `artifacts/p2.1-input-origin-*.json` and `.log` before any P2 decision.
